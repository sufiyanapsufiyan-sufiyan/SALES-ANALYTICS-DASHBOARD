# 📊 Sales Analytics Dashboard

An interactive **Sales Analytics Dashboard built in Microsoft Excel** to analyze sales performance, profitability, customers, products, regions, and order trends.

## 🎯 Project Overview

This project presents an interactive Excel dashboard designed to provide a clear overview of business sales performance.

The dashboard includes KPIs, charts, filters, and visual analysis to help understand sales trends and identify high-performing regions, products, and customers.

## 📌 Key Features

- 💰 Total Revenue
- 📈 Monthly Sales Trend
- 🏆 Top 5 Customers by Revenue
- 🌎 Sales by Region
- 💵 Profit by Region
- 📦 Sales & Cost by Product
- 🛍️ Sales by Item Category
- 📊 Quantity Sold by Product
- 📅 Orders Over Time
- 🎛️ Interactive Filters / Slicers

## 🛠️ Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Timelines
- Excel Charts
- Data Analysis
- Dashboard Design

## 📊 Dashboard Sections

### KPI Cards
The dashboard provides a quick summary of important business metrics such as:

- Total Revenue
- Total Quantity
- Total Orders
- Average Order Value
- Total Customers

### Sales Analysis

The dashboard analyzes:

- Monthly sales performance
- Regional sales
- Product-level sales
- Category-level sales
- Customer revenue
- Order trends

### Customer Analysis

The **Top 5 Customers by Revenue** section highlights the customers contributing the highest revenue.

### Product Analysis

Product performance is analyzed using:

- Sales
- Cost
- Quantity Sold
- Product Category
